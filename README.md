# poutine-lab.com | Technical Portfolio

Live Site: [poutine-lab.com](https://poutine-lab.com)

This repository houses the source code and configuration for my professional portfolio and technical showcase. It serves as a centralized hub for my work in Identity & Access Management (IAM), Zero Trust architecture, and workflow automation.

## Architecture & Deployment

This project leverages a modern GitOps workflow to ensure rapid, secure deployments:
* **Hosting:** [Cloudflare Pages](https://pages.cloudflare.com/)
* **Styling:** Tailwind CSS (Dark Mode optimized)
* **CI/CD:** Automated edge deployments triggered by commits to the `main` branch.

## Technical Showcases Included
* Enterprise Identity-as-Code (Okta & Terraform)
* Zero Trust Automation Pipelines (Tines, n8n, Okta Workflows)
* Secure Homelab Infrastructure (Cloudflare Tunnels, Docker, Grafana)
* Local AI & MCP Integration (LM Studio, Ollama)
