Acquisition & Data Integration

Migration

Challenge: Integrating disparate identity systems during a major corporate acquisition without disrupting the user experience.

Solution: Migrated source-of-truth data from Workday to a GraphQL-based database using the "Anything-as-a-Source" (XaaS) feature and REST API orchestration.

Impact: Successfully unified the identity posture of the combined organization with minimal user disruption.

Private AI & MCP Research

R&D

Challenge: High costs and privacy concerns associated with public cloud LLMs for internal research and development.

Solution: Benchmarked and deployed private, off-grid LLM inference on Apple M3 Pro hardware, configuring Model Context Protocol (MCP) servers.

Impact: Established a secure framework for local AI exploration and development, expanding what engineers can accomplish.
